\section{ความเป็นมาและความสำคัญของปัญหา}
% -----------------------------------------------------------

ปัจจุบัน ฟุตบอลเป็นกีฬาที่ได้รับความนิยมอย่างมากทั่วโลก และมีการเก็บสถิติการแข่งขันเอาไว้อย่างเป็นระบบ ไม่ว่าจะเป็นผลการแข่งขัน สถิติการครองบอล การยิงประตู ค่าความคาดหวังในการทำประตู (Expected Goals: xG) ไปจนถึงอัตราต่อรองจากเจ้ามือรับพนัน (Odds) โดยเฉพาะการแข่งขันพรีเมียร์ลีกอังกฤษ (English Premier League) ซึ่งมีเตะกันถึง 380 นัดต่อฤดูกาล ทำให้เกิดชุดข้อมูลขนาดใหญ่ที่เหมาะมากสำหรับการนำกระบวนการวิทยาการข้อมูล (Data Science) และการเรียนรู้ของเครื่อง (Machine Learning) มาใช้ศึกษาและวิเคราะห์ความสัมพันธ์ของปัจจัยต่าง ๆ กับผลการแข่งขัน

อย่างไรก็ตาม การจะทำนายผลบอลให้แม่นยำถือเป็นเรื่องที่ท้าทายมาก เพราะผลการแข่งขันขึ้นอยู่กับปัจจัยที่ผันผวนอยู่ตลอดเวลา งานวิจัยในอดีตส่วนใหญ่มักใช้เฉพาะสถิติสกอร์ย้อนหลัง เช่น แบบจำลองเชิงสถิติตระกูล Poisson และ Weibull \cite{dixon1997modelling} หรือระบบการจัดอันดับคะแนนอย่าง Elo Rating, pi-ratings และ Berrar ratings \cite{hvattum2010using, berrar2019incorporating} ซึ่งจากการศึกษาของ Hubáček และคณะ \cite{hubacek2021forty} ที่ทดลองกับชุดข้อมูลกว่า 2.1 แสนนัด จาก 52 ลีกทั่วโลก พบว่าแบบจำลองที่ใช้แค่สถิติย้อนหลังจะทำความแม่นยำได้จำกัดอยู่แค่ช่วงร้อยละ 47.8--48.6 เท่านั้น ในขณะที่ราคาอัตราต่อรองของเจ้ามือรับพนัน ซึ่งประมวลผลจากข้อมูลเชิงลึกและสภาพตลาดจริง กลับทำความแม่นยำได้สูงถึงประมาณร้อยละ 55 และยังไม่มีโมเดลการเรียนรู้ของเครื่องตัวไหนที่ชนะราคาต่อรองได้อย่างชัดเจน

จากจุดนี้ กลุ่มของผู้จัดทำจึงมองเห็นช่องว่างว่า การใช้แค่สถิติย้อนหลังอย่างเดียวอาจไม่เพียงพอ โครงงานนี้จึงมีแนวคิดที่จะดึงข้อมูลมิติอื่น ๆ ที่ไม่ได้อยู่ในสกอร์การแข่งขันเข้ามาช่วยทำนายด้วย ได้แก่ คะแนน Elo Rating เพื่อวัดความแข็งแกร่งของทีม, ค่า xG เพื่อดูประสิทธิภาพเกมรุกและเกมรับ, รายชื่อผู้เล่นตัวจริง (Lineup) และสถิติผู้เล่นหลักที่บาดเจ็บ เพราะงานวิจัยก่อนหน้านี้ชี้ว่า การเอาข้อมูลบริบทเหล่านี้มาร่วมวิเคราะห์กับโมเดลการเรียนรู้ของเครื่อง จะช่วยเพิ่มความแม่นยำในการทำนายได้ดียิ่งขึ้น \cite{berrar2019incorporating}

ดังนั้น โครงงานนี้จึงมุ่งเน้นการรวบรวมข้อมูลการแข่งขันฟุตบอลย้อนหลังตั้งแต่ฤดูกาล 2014--2015 ถึง 2025--2026 จากหลายแหล่งข้อมูลสาธารณะ (Kaggle, FBref, Transfermarkt และ Understat) \cite{kaggle2024, fbref2024, transfermarkt2024, understat2024} เพื่อนำมาประมวลผล วิเคราะห์ความสำคัญของตัวแปร (Feature Importance) และพัฒนาแบบจำลองการเรียนรู้ของเครื่องสำหรับ\textbf{ทำนายผลการแข่งขันพรีเมียร์ลีกอังกฤษ} ออกเป็น 3 หน้า คือ ทีมเจ้าบ้านชนะ (Home Win) เสมอ (Draw) และทีมเยือนชนะ (Away Win) พร้อมทั้งเปรียบเทียบประสิทธิภาพกับราคาอัตราต่อรองเพื่อประโยชน์ในการวิเคราะห์เชิงสถิติ

\section{วัตถุประสงค์}
% -----------------------------------------------------------

\begin{enumerate}[label=\arabic*)]
    \item เพื่อศึกษาและฝึกปฏิบัติกระบวนการวิทยาการข้อมูลอย่างครบวงจร ตั้งแต่การรวบรวมข้อมูลหลายแหล่ง การเชื่อมโยงข้อมูล การทำความสะอาด การสำรวจข้อมูล ไปจนถึงการพัฒนาและประเมินแบบจำลอง
    \item เพื่อวิเคราะห์หาปัจจัยที่มีอิทธิพลต่อผลการแข่งขันฟุตบอลพรีเมียร์ลีกอังกฤษ จากตัวแปรสถิติเชิงลึก ค่า xG, คะแนน Elo, ข้อมูลการบาดเจ็บของผู้เล่นหลัก และราคาอัตราต่อรอง
    \item เพื่อพัฒนาและเปรียบเทียบประสิทธิภาพของแบบจำลองการเรียนรู้ของเครื่องในการทำนายผลการแข่งขันพรีเมียร์ลีกอังกฤษ
    \item เพื่อเปรียบเทียบประสิทธิภาพของแบบจำลองที่พัฒนาขึ้น กับราคาอัตราต่อรองของเจ้ามือรับพนันและผลการศึกษาจากงานวิจัยที่ผ่านมา \cite{hubacek2021forty}
\end{enumerate}

\section{ขอบเขตและข้อจำกัดของโครงงาน}
% -----------------------------------------------------------

\subsection{ขอบเขตของโครงงาน}

\begin{enumerate}[label=\arabic*)]
    \item \textbf{ขอบเขตด้านข้อมูล:} ใช้ข้อมูลย้อนหลังตั้งแต่ฤดูกาล 2014--2015 เป็นต้นไป จากแหล่งข้อมูลสาธารณะ 4 แหล่งหลัก ได้แก่
    \begin{itemize}
        \item \textit{Kaggle} (ชุดข้อมูล \textit{marcohuiii/english-premier-league-epl-match-data-2000-2025}): ใช้ดึงข้อมูลผลการแข่งขัน สถิติในเกม และราคาอัตราต่อรอง \cite{kaggle2024}
        \item \textit{FBref}: ใช้ดึงข้อมูลรายชื่อผู้เล่นตัวจริง (Lineup) และสถิติตัวผู้เล่น (ข้อมูลเริ่มตั้งแต่ปี 2015) \cite{fbref2024}
        \item \textit{Transfermarkt}: ใช้ดึงข้อมูลการย้ายทีม และสถิติการบาดเจ็บของผู้เล่น (ข้อมูลเริ่มตั้งแต่ปี 2014) \cite{transfermarkt2024}
        \item \textit{Understat}: ใช้ดึงสถิติค่าความคาดหวังในการทำประตู (xG) และสถิติรายบุคคล (ข้อมูลเริ่มตั้งแต่ปี 2014) \cite{understat2024}
    \end{itemize}
    \item \textbf{ขอบเขตด้านการทำนายและลีก:} แม้ว่าระบบจะจัดเก็บข้อมูลครอบคลุม 5 ลีกใหญ่ของยุโรป (พรีเมียร์ลีกอังกฤษ, ลาลีกา, บุนเดสลีกา, เซเรียอา และลีกเอิง) เพื่อให้โครงสร้างข้อมูลสมบูรณ์ แต่\textbf{ตัวโมเดลจะฝึกและทำนายผลเฉพาะพรีเมียร์ลีกอังกฤษเพียงลีกเดียวเท่านั้น}
    \item \textbf{ขอบเขตด้านกระบวนการทำงาน:} ดำเนินการตามกระบวนการวิทยาการข้อมูล 5 ขั้นตอน ได้แก่ การตั้งคำถามวิจัย (Question Refinement), การเก็บรวบรวมและเชื่อมโยงข้อมูล (Data Collection \& Merging), การทำความสะอาดและสำรวจข้อมูล (Data Cleaning \& Exploration), การสร้างแบบจำลอง (Model Building) และการสรุปผลลัพธ์ (Communication of Results)
    \item \textbf{ขอบเขตด้านตัวแปรเชิงทำนาย (Features):} ครอบคลุมสถิติผลงานย้อนหลัง, ค่า xG, ผลต่างคะแนนความแข็งแกร่ง (Elo Difference), อัตราต่อรอง (Odds) และการสร้างตัวแปรดัชนีผู้เล่นหลักที่บาดเจ็บ (Key Injured Players) โดยนิยามผู้เล่นหลักจากการลงสนามเป็นตัวจริงเกินร้อยละ 50 ของนัดที่ลงเล่นได้ ทั้งนี้ ข้อมูล FBref ที่เริ่มในปี 2015 จะจัดการเรื่องค่าที่ขาดหาย (Missing Values) ในขั้นตอนการเตรียมข้อมูล
    \item \textbf{ขอบเขตด้านแบบจำลอง:} พัฒนาและเปรียบเทียบประสิทธิภาพของแบบจำลองการจำแนกประเภท 3 อัลกอริทึม ได้แก่ Logistic Regression (ใช้เป็นเกณฑ์วัดพื้นฐาน: Baseline), Decision Tree และ Random Forest โดยพัฒนาด้วยภาษา Python และไลบรารี Scikit-learn \cite{scikit-learn, pandas2010}
    \item \textbf{ขอบเขตด้านการแบ่งชุดข้อมูล:} แบ่งชุดข้อมูลสำหรับ Train/Validation/Test \textbf{ตามลำดับเวลา (ไม่สุ่ม)} เพื่อป้องกันปัญหาข้อมูลรั่วไหลจากอนาคต (Data Leakage) และกำหนดช่วง 5 นัดแรกของทุกฤดูกาลเป็น Burn-in Period โดยไม่นำมาประเมินผล เนื่องจากข้อมูลสถิติย้อนหลังยังไม่เพียงพอ
    \item \textbf{ตัวชี้วัดประสิทธิภาพ:} ประเมินด้วย Accuracy, F1-score, Confusion Matrix, Cross-Entropy Loss (Log Loss) และ Ranked Probability Score (RPS) ร่วมกับการวิเคราะห์เส้นโค้ง Calibration Curve และวัดระดับความสำคัญของตัวแปร (Feature Importance)
\end{enumerate}

\subsection{ข้อจำกัดของโครงงาน}

\begin{enumerate}[label=\arabic*)]
    \item แบบจำลองถูกพัฒนาและทดสอบกับพรีเมียร์ลีกอังกฤษเป็นหลัก จึงอาจไม่สามารถนำไปใช้ทำนายผลการแข่งขันในลีกอื่นได้ทันที
    \item แบบจำลองทำนายผลลัพธ์ออกเป็น 3 หน้าเท่านั้น (เจ้าบ้านชนะ, เสมอ, ทีมเยือนชนะ) โดยไม่ได้ทำนายจำนวนประตูหรือสกอร์จริง
    \item ข้อมูลมาจากหลายแหล่งที่มีปีเริ่มต้นไม่เท่ากัน (FBref เริ่มปี 2015 ส่วนแหล่งอื่นเริ่มปี 2014) และการเรียกชื่อทีมหรือชื่อนักเตะไม่เหมือนกัน จึงต้องใช้อัลกอริทึมจับคู่ชื่อ (Name Mapping) ซึ่งอาจมีความคลาดเคลื่อนสะสมจากการเชื่อมข้อมูล
    \item ข้อมูลประวัติการบาดเจ็บขึ้นอยู่กับความสมบูรณ์ของฐานข้อมูลต้นทาง และการระบุสถานะวันแข่งขันอ้างอิงจากช่วงเวลาก่อนแข่ง ซึ่งอาจไม่สะท้อนความฟิตจริงในสนามทั้งหมด
    \item โครงงานไม่ได้นำปัจจัยเชิงคุณภาพที่ไม่ปรากฏในสถิติ เช่น ขวัญกำลังใจ สภาพอากาศ สภาพสนาม หรือข่าวสารนอกสนาม มาร่วมวิเคราะห์
    \item การดำเนินงานอยู่ภายใต้ระยะเวลาจำกัดประมาณ 6 สัปดาห์ และผลลัพธ์ที่ได้มีวัตถุประสงค์เพื่อการศึกษาเชิงสถิติเท่านั้น
\end{enumerate}

\section{ประโยชน์ที่คาดว่าจะได้รับ}
% -----------------------------------------------------------

\begin{enumerate}[label=\arabic*)]
    \item ผู้จัดทำได้ฝึกปฏิบัติกระบวนการวิทยาการข้อมูลอย่างครบวงจรกับชุดข้อมูลกีฬาจริงที่มีความซับซ้อนและมาจากหลายแหล่ง
    \item ได้แบบจำลองการเรียนรู้ของเครื่องที่สามารถทำนายผลพรีเมียร์ลีกอังกฤษได้ พร้อมทั้งทราบปัจจัยสำคัญที่มีผลต่อการแข่งขัน
    \item ได้คำตอบเชิงประจักษ์ว่า การเพิ่มข้อมูลระดับตัวผู้เล่น (การบาดเจ็บ) และตัวชี้วัดขั้นสูง (Elo, xG) ช่วยเพิ่มประสิทธิภาพการทำนายได้ดีกว่าแบบจำลองสถิติย้อนหลังแบบเดิมหรือไม่ \cite{hubacek2021forty, berrar2019incorporating}
    \item ได้แนวทางและองค์ความรู้ในการนำเทคนิค Data Science และการวิเคราะห์ Feature ไปประยุกต์ใช้กับข้อมูลกีฬาประเภทอื่น ๆ ต่อไป
\end{enumerate}
