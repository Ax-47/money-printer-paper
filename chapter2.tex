\subsection{กระบวนการวิทยาการข้อมูล (Data Science Process)}

กระบวนการวิทยาการข้อมูลเป็นกรอบการทำงานเชิงระบบที่นำข้อมูลขนาดใหญ่มาประมวลผลและวิเคราะห์ เพื่อค้นหารูปแบบหรือสร้างคุณประโยชน์ ในโครงงานนี้ประยุกต์ใช้กระบวนการ 5 ขั้นตอน ได้แก่

\begin{enumerate}[label=\arabic*)]
    \item \textbf{การกำหนดวัตถุประสงค์และคำถามวิจัย (Question Refinement):} กำหนดโจทย์ในการทำนายผลการแข่งขันฟุตบอลพรีเมียร์ลีกอังกฤษออกเป็น 3 หน้า (เจ้าบ้านชนะ, เสมอ, ทีมเยือนชนะ)
    \item \textbf{การเก็บรวบรวมข้อมูล (Data Collection \& Merging):} การดึงข้อมูลสถิติการแข่งขัน อัตราต่อรอง รายชื่อผู้เล่น และข้อมูลการบาดเจ็บจากหลายแหล่งสาธารณะมารวมเข้าด้วยกัน \cite{kaggle2024, fbref2024, transfermarkt2024, understat2024}
    \item \textbf{การสำรวจและเตรียมข้อมูล (Data Exploration \& Feature Engineering):} การทำความสะอาดข้อมูล จัดการค่าที่ขาดหาย ค้นหาความสัมพันธ์ และสร้างตัวแปรใหม่ เช่น คะแนน Elo Difference, ค่า xG และดัชนีผู้เล่นหลักที่บาดเจ็บ
    \item \textbf{การสร้างและประเมินแบบจำลอง (Model Building \& Evaluation):} การฝึกฝนโมเดลการเรียนรู้ของเครื่อง และประเมินประสิทธิภาพด้วยตัวชี้วัดต่าง ๆ \cite{scikit-learn}
    \item \textbf{การสรุปและสื่อสารผลลัพธ์ (Communication of Results):} การสรุปผลการวิเคราะห์ เปรียบเทียบประสิทธิภาพกับราคาอัตราต่อรอง และนำเสนอระดับความสำคัญของฟีเจอร์ (Feature Importance)
\end{enumerate}

\subsection{ระบบวัดระดับความแข็งแกร่ง (Elo Rating System)}

ระบบคะแนน Elo เป็นวิธีทางสถิติที่ใช้คำนวณระดับทักษะความแข็งแกร่งของทีมแข่งขัน คะแนนจะถูกปรับเปลี่ยนตามผลการแข่งขันจริงและระดับความแข็งแกร่งของคู่แข่ง โดยทีมที่ชนะทีมที่มีคะแนนสูงกว่าจะได้คะแนนเพิ่มขึ้นมากกว่าการชนะทีมที่อ่อนกว่า \cite{hvattum2010using} ในโครงงานนี้ ผลต่างคะแนน Elo (Elo Difference) ระหว่างทีมเจ้าบ้านและทีมเยือนถูกนำมาใช้เป็นฟีเจอร์สำคัญในการสะท้อนความได้เปรียบเชิงศักยภาพของทีม

\subsection{ค่าความคาดหวังในการทำประตู (Expected Goals: xG)}

ค่า xG เป็นตัวชี้วัดเชิงสถิติขั้นสูงที่ใช้ประเมินคุณภาพของโอกาสในการยิงประตู โดยคำนวณความน่าจะเป็นที่ลูกยิงแต่ละครั้งจะกลายเป็นประตู (มีค่าระหว่าง 0 ถึง 1) ขึ้นอยู่กับตำแหน่งการยิง มุมในการยิง ประเภทการส่งบอล และบริบทของเกม ค่า xG ช่วยให้มองเห็นประสิทธิภาพเกมรุกและเกมรับที่แท้จริงของทีม ซึ่งสะท้อนฟอร์มการเล่นได้ดีกว่าผลสกอร์แพ้-ชนะแบบดั้งเดิม \cite{understat2024}

\subsection{อัตราต่อรองของเจ้ามือรับพนัน (Betting Market Odds)}

อัตราต่อรองในตลาดเดิมพันนอกจากจะใช้ในเชิงการพนันแล้ว ในทางวิทยาการข้อมูลยังถือเป็นตัวชี้วัดความน่าจะเป็น (Implied Probability) ที่ผ่านการประมวลผลข้อมูลเชิงลึกและปัจจัยแวดล้อมโดยผู้เชี่ยวชาญ \cite{dixon1997modelling} ในโครงงานนี้ ราคาอัตราต่อรองสำหรับผลการแข่งขัน 3 รูปแบบ จะถูกแปลงให้อยู่ในรูปของค่าความน่าจะเป็น เพื่อใช้เป็นเกณฑ์อ้างอิงมาตรฐาน (Benchmark) ในการเปรียบเทียบประสิทธิภาพกับแบบจำลองที่พัฒนาขึ้น \cite{hubacek2021forty}

\subsection{การจำแนกประเภทด้วยการเรียนรู้ของเครื่อง (Machine Learning Classification)}

การทำนายผลการแข่งขันฟุตบอลถูกกำหนดให้เป็นโจทย์การจำแนกประเภทแบบหลายกลุ่ม (Multiclass Classification) 3 กลุ่ม ได้แก่ ทีมเจ้าบ้านชนะ (Home Win: H), เสมอ (Draw: D) และทีมเยือนชนะ (Away Win: A) โดยเลือกใช้แบบจำลองผ่านไลบรารี Scikit-learn \cite{scikit-learn} ดังนี้

\paragraph{1) Logistic Regression}
เป็นแบบจำลองเชิงเส้นทางสถิติที่ใช้วิเคราะห์ความน่าจะเป็น เหมาะสำหรับใช้เป็นแบบจำลองพื้นฐาน (Baseline Model) เนื่องจากคำนวณได้เร็ว ไม่ซับซ้อน และตีความผลลัพธ์ผ่านค่าสัมประสิทธิ์ของตัวแปรได้ง่าย

\paragraph{2) Decision Tree}
เป็นแบบจำลองโครงสร้างต้นไม้ที่ตัดสินใจแบ่งข้อมูลตามเงื่อนไขของตัวแปรตามเกณฑ์ เช่น Gini Impurity หรือ Information Gain มีจุดเด่นคือเข้าใจเงื่อนไขการทำงานได้ง่าย แต่เสี่ยงต่อปัญหาการเรียนรู้ดีเกินไป (Overfitting)

\paragraph{3) Random Forest}
เป็นเทคนิค Ensemble Learning ที่สร้าง Decision Tree จำนวนหลายต้นและใช้วิธีรวมผลการตัดสินใจ (Majority Voting) เพื่อสรุปผลการทำนาย ช่วยลดปัญหา Overfitting เพิ่มความแม่นยำ และสามารถวัดระดับความสำคัญของตัวแปร (Feature Importance) ได้ดี \cite{berrar2019incorporating}

\section{งานวิจัยที่เกี่ยวข้อง}
% -----------------------------------------------------------

ในส่วนนี้เป็นการทบทวนวรรณกรรมและงานวิจัยที่นำเทคนิควิทยาการข้อมูลและการเรียนรู้ของเครื่องมาใช้ในการทำนายผลกีฬา เพื่อหาแนวทางและช่องว่างในการพัฒนาโครงงาน

\subsection{การทำนายผลฟุตบอลด้วยแบบจำลองเชิงสถิติและอัตราต่อรอง}

งานวิจัยยุคแรกมักใช้สถิติการแข่งขันย้อนหลัง เช่น จำนวนประตูที่ทำได้ ฟอร์มเหย้า-เยือน ผ่านโมเดลเชิงสถิติตระกูล Poisson \cite{dixon1997modelling} หรือระบบจัดอันดับ Rating \cite{hvattum2010using, constantinou2013determining} ซึ่งจากการประเมินและทบทวนวรรณกรรมย้อนหลัง 40 ปีโดย Hubáček และคณะ \cite{hubacek2021forty} ที่ทดสอบกับชุดข้อมูลกว่า 2.1 แสนนัด พบว่าแบบจำลองที่ใช้เพียงผลสกอร์ย้อนหลังมีขีดจำกัดความแม่นยำอยู่เพียงร้อยละ 47.8--48.6 เท่านั้น ในขณะที่ราคาอัตราต่อรองจากตลาดเดิมพันกลับให้ความแม่นยำสูงกว่า (ประมาณร้อยละ 53--55) เนื่องจากสะท้อนข้อมูลเชิงลึกในตลาดได้อย่างรวดเร็ว อย่างไรก็ตาม การใช้เพียงอัตราต่อรองอย่างเดียวจะไม่สามารถอธิบายปัจจัยภายในหรือบริบทของทีมได้ครบถ้วน

\subsection{การใช้ Machine Learning ร่วมกับการวิเคราะห์ตัวแปรระดับผู้เล่น}

งานวิจัยหลายฉบับทดลองใช้อัลกอริทึม Logistic Regression, Decision Tree และ Random Forest ในการทำนายผลฟุตบอล โดยใช้สถิติการครองบอล การยิงประตู และฟอร์มย้อนหลัง ซึ่งพบว่า Random Forest มักให้ผลลัพธ์ที่ดีกว่าโมเดลเชิงเส้น อย่างไรก็ตาม งานวิจัยส่วนใหญ่มักมองข้ามปัจจัยด้านตัวผู้เล่น เช่น ข้อมูลไลน์อัปจริงและสถิติผู้เล่นหลักที่บาดเจ็บ (Key Injured Players) ซึ่ง Berrar และคณะ \cite{berrar2019incorporating} ได้ชี้ให้เห็นว่าการดึงข้อมูลเฉพาะทางและบริบทแวดล้อม (Domain Knowledge) เข้ามาประกอบ จะช่วยให้โมเดล Machine Learning ทำนายผลได้แม่นยำยิ่งขึ้น

\subsection{ภาษา Python และไลบรารีสำหรับ Data Science}

ภาษา Python เป็นภาษาหลักที่ใช้ในการดำเนินโครงงาน เนื่องจากมีระบบนิเวศของไลบรารีที่สนับสนุนงานด้าน Data Science อย่างครบถ้วน ได้แก่

\begin{enumerate}[label=\arabic*)]
    \item \textbf{Pandas และ NumPy:} ใช้สำหรับการจัดการ จัดเตรียม ดึงข้อมูล ทำความสะอาด และประมวลผลเมทริกซ์ \cite{pandas2010}
    \item \textbf{Scikit-learn:} ใช้พัฒนาแบบจำลองการเรียนรู้ของเครื่อง (Logistic Regression, Decision Tree, Random Forest) การแบ่งชุดข้อมูล Train/Validation/Test และการประเมินวัดผล \cite{scikit-learn}
    \item \textbf{Matplotlib และ Seaborn:} ใช้ในการทำ Data Visualization เพื่อสำรวจข้อมูลและแสดงผลกราฟความสำคัญของตัวแปร (Feature Importance)
\end{enumerate}

\subsection{สภาพแวดล้อมการพัฒนา (Development Environment)}

\begin{enumerate}[label=\arabic*)]
    \item \textbf{Jupyter Notebook / Google Colab:} ใช้เป็นเครื่องมือหลักในการเขียนโค้ด ทดสอบสมมติฐาน และสำรวจข้อมูลแบบ Interactive
    \item \textbf{แหล่งชุดข้อมูลสาธารณะ (Kaggle, FBref, Transfermarkt, Understat):} เป็นแหล่งจัดเก็บข้อมูลผลการแข่งขัน อัตราต่อรอง สถิติ xG รายชื่อไลน์อัป และสถิติการบาดเจ็บของนักเตะ \cite{kaggle2024, fbref2024, transfermarkt2024, understat2024}
\end{enumerate}
